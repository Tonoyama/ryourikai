# Inception — 料理会の意図とスコープ

## 目的

同期エンジニア12名へラーメン2杯を中心とした **コース料理** を振る舞う。家庭料理の延長ではなく、コースとして体験設計された一会。

## 参加者

- 主催: ytonoyam
- ゲスト: 同期エンジニア 12名
- 体験形態: 着席コース料理

## 成功基準

1. **コース流れ**が破綻なく完走（前菜 → Ramen I → お口直し → Ramen II → デザート）
2. **2種のラーメン**がそれぞれ独自の輪郭を持って成立（清湯と豚骨で対比）
3. **食材ナラティブ**が機能する：比内地鶏・有明海苔など地域性を語れる
4. **ノンアルペアリング**でアルコールに頼らず体験を作れる
5. 全員が満腹で帰る（残量・残飯が出ない量設計）

## コース構成

| 順 | Unit | 内容 |
|---|---|---|
| 1 | `zensai-maguro` | 生本鮪中落ち、青種・赤種わさび 2種、愛知 三年木桶熟成たまり |
| 2 | `ramen-i-chintan` | 比内地鶏とアサリの清湯ラーメン（7:3 スープ、95g/杯、ツミレ実山椒風味） |
| 3 | `palate-cleanser-granita` | 静岡 手摘み新生茶葉のグラニテ、広島 レモンの香り |
| 4 | `ramen-ii-tonkotsu` | 俺たちの濃厚豚骨ラーメン（濃厚豚骨、150ml/杯、豚焼豚） |
| 5 | `dessert-raspberry-pi` | Raspberry Pi スナップドラゴン添え（コンフィチュール・バニラトンカ豆アイス・マデイラレデュイール） |
| — | `drinks` | ノンアルペアリング（氷出し緑茶・みかんジュース・エルダーフラワー他） |

## 制約

- 厨房：自宅キッチン1箇所
- 製麺機：ATLAS 150（パスタマシン）
- 鍋容量・コンロ口数の制約あり
- 在庫粉 10種・在庫醤油 13種・在庫みりん 1種を最大活用
