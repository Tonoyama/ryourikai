AI-DLC とは何か

AI-Driven Development Lifecycle

  • 2025年に AWS が提唱した、AI を前提に再設計された
    ソフトウェア開発ライフサイクル
  • 従来の SDLC（Waterfall / Agile）は
    "人間が書き、AI は補助" という前提
  • AI-DLC は "AI が一次実装し、人間がレビュー・意思決定する"
    に主従を逆転させた前提モデル

3つの特徴

  • ① Intent-first
    「何を作るか」を CLAUDE.md / spec / PRD として明示的に書き、それを AI と共有する
  • ② Unit 駆動
    機能を AI 1セッションで完結する小さな Unit に分解し、独立に開発・テスト
  • ③ Loop で進化
    Inception → Construction → Operations が 何度も回る短いループ。本番フィードバックが次の意図に直結する

出典: AWS Builder Blog (2025)・Amazon Q Developer 公式ドキュメント

3D printing / Raspberry Pi / 17F LODGE

Raspberry Pi のパイ焼いてみてみたい

  • 料理会でRaspberry Piのパイを焼いたら面白そう
  • スナップドラゴン(食用花の金魚草の英名)も飾りにしたらより面白そう
  • カンファレンスの自己紹介のネタとしても面白いかも

試作：手切りでは うまく切り取れなかった

  • 最初は 手切りで Pi ロゴを再現してみた
  • 葉のヘキサゴンは円が多すぎてナイフでは精度が出ない
  • 線がガタつく・大きさが揃わない・生地が裂ける
  • → 紀尾井町 17F LODGE の 3D プリンタで型を印刷することを決意
  • = "普通のクッキー型は売っていない、なら作るしかない"

Claude と Python で 3D モデル化

# make_cutter.py（~500 行）
import numpy as np
from PIL import Image
from scipy import ndimage

TARGET_WIDTH_MM    = 63.0  # 63mm / 100mm の2サイズ
CUTTER_HEIGHT_MM   = 12.0  # 5mm 生地 + 7mm grip
WALL_THICKNESS_MM  = 1.2
FLANGE_WIDTH_MM    = 2.5
N_OUTER            = 600   # 外周サンプリング
N_HOLE             = 96    # 穴サンプリング
SOLID_DIAMETER_MM  = 5.0   # 小さい円は実心ポスト

# Pipeline:
#   PNG (公式 Pi ロゴ)
#     ↓  PIL + scipy.ndimage
#   silhouette mask + 内部穴マスク
#     ↓  Moore-Neighbor 境界トレース
#   外側多角形 + 穴多角形
#     ↓  法線オフセット
#   inner / flange / hole-inner リング
#     ↓  組み立て
#   outer cutter + 内部 tube + 連結 strut
#     ↓
#   SVG プレビュー + ASCII STL
  • 入力：Raspberry Pi 公式ロゴ PNG
  • Claude Code に「Pi ロゴから生地カッターの STL を作って」と依頼
  • Python（numpy / PIL / scipy） で実装
  • 処理は 3 段階：
    ① PNG（ロゴ画像）→ ロゴだけを切り出し
    ② SVG（2D の輪郭線）に変換
    ③ STL（厚みを付けた 3D 型）として書き出し
  • 出力：raspi_cutter_63mm.stl / _100mm.stl

設計の工夫：印刷の向きでサポート材を回避

前提：3D プリンタは下から上に層を積む。空中に張り出した部分は "サポート材"（捨て柱）で支える必要があり、印刷後に剥がす作業＋表面に跡が残る。

✕ 刃を下にして印刷

刃（細い）が接地 → 持ち手のフランジ（広い）が 空中に張り出す
サポート材が必要 → 剥がす手間＋刃の表面に跡

✓ 持ち手を下にして印刷（採用）

広い 持ち手のフランジを接地 → 上に向かって刃まで地続きに積み上がる
→ サポート材ゼロ。剥がし作業なし＋刃側がツルツル仕上がる

make_cutter.py の FLIP_FOR_PRINT = True パラメータで自動で上下反転
