# ソースガストリック（12人前）

グラニュー糖のカラメルにバルサミコ酢を合わせた甘酸っぱいソース。バニラアイスの甘みを切り、デザートに奥行きを与える。

---

## 基本情報

| 項目 | 内容 |
|------|------|
| 提供人数 | 12人 |
| 仕上がり量 | 約120〜130ml |
| 1人前目安 | 約10ml（小さじ2程度） |
| 仕込み | 当日または前日（冷蔵保存可） |

---

## 材料

| 食材 | 分量 |
|------|------|
| グラニュー糖 | 150 g |
| 水（カラメル用） | 40 ml |
| バルサミコ酢（アグロソリ IGP） | 75 ml |

---

## 手順

### 1. カラメルを作る

1. 小鍋にグラニュー糖150gと水40mlを入れる
2. 中火にかけ、**鍋を揺すらず・混ぜず**に加熱する（混ぜると結晶化する）
3. 縁が色づき始めたら鍋を軽く回して均一にする
4. **濃い琥珀色**になったら火を止める（薄すぎると苦味が足りず、黒すぎると焦げ臭くなる）

> **目安：** 煙が薄く立ち始め、甘い香りからほろ苦い香りに変わった瞬間が止め時。

### 2. バルサミコ酢を加える

1. 火を止めた状態でバルサミコ酢75mlを**少しずつ**加える
2. **激しく跳ねるので顔や手を離す**（一気に入れない）
3. 3〜4回に分けて加え、そのたびに鍋を回して混ぜる

### 3. 煮詰めて仕上げる

1. 再度弱火にかけ、カラメルが完全に溶けるまで混ぜる
2. とろみが出るまで**2〜3分煮詰める**
3. スプーンの背に薄くコーティングされる程度が目標
4. 冷めると固くなるので、**やや緩いかな、という段階**で火を止める

### 4. 保存

1. 耐熱容器に移して粗熱を取る
2. 冷蔵保存可（最大3日）
3. 固まりすぎた場合は提供前に軽く湯煎で緩める

---

## 提供

1. バニラアイスをスクープして盛り付ける
2. ソースガストリックを**アイスの周りに垂らす**（上からかけるとアイスが溶ける）
3. 皿にラインを引くように盛ると見栄えが良い

---

## 備考

- **酢の投入時の安全：** カラメルは170℃以上。冷たい酢を入れると爆発的に蒸気が上がる。必ず少量ずつ、顔を離して加える
- **粘度の調整：** 煮詰めすぎた場合は水を小さじ1ずつ加えて調整。緩すぎた場合は再度弱火で煮詰める
- **バルサミコ酢：** アグロソリ アチェート・バルサミコ IGP 500ml使用。加熱しても風味が残るIGP品質
