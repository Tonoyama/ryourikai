# バニラアイス（トンカ豆インフュージョン・600g・クネル提供）

アングレーズベースのリッチなバニラアイス。**バニラ × トンカ豆**の古典的ペアリングで複雑な深みを構築。45%高脂肪生クリーム使用、粉末水あめで再結晶化防止。**12人前 × 50g/クネル = 600g** で提供。

---

## 基本情報

| 項目 | 内容 |
|------|------|
| 提供人数 | 12人 |
| 仕上がり量 | **約600g**（クネル提供 50g/人） |
| 提供スタイル | **クネル**（湯につけたスプーン2本で楕円整形） |
| 仕込み2段階 | **❶ D-2（金）深夜：アングレーズ＋合わせる→冷蔵エイジング 8-10h** ／ **❷ D-1（土）朝：チャーニング 2バッチ→深冷凍** |
| アイスクリームメーカー | **家庭用 300ml/回・容器は事前12-24h冷凍** / 540ml混合液を **270ml × 2バッチ** でチャーニング |
| 保存 | 冷凍密閉・1週間 |
| 提供前の準備 | **提供30分前に冷凍→冷蔵 移動**でテンパリング（クネル整形しやすい状態に） |

## 材料

| 食材 | 分量 | 役割 |
|------|------|------|
| 卵黄 | **3個**（約60g） | アングレーズベース・乳化・コク |
| 牛乳（成分無調整） | **300 ml** | アングレーズ＋**トンカ抽出媒体** |
| グラニュー糖 | **50 g** | 甘み（コース調和優先で控えめ） |
| **塩** | **0.7 g** | **甘味の輪郭強調＋バニラ/トンカの香り立ち**（0.6-0.8gの範囲） |
| **トンカ豆** | **1/4個**（おろし金で削る） | **深み・チェリー・アーモンド・木質香** |
| 生クリーム（45%） | **130 ml** | 脂肪・口溶け（35%×400ml と同等の脂肪量＝140g） |
| 粉末水あめ | **55 g** | **再結晶化防止強化・シャリシャリ抑制**（40g→55gに増量） |
| バニラペースト | **3 g**（小さじ約 1/2弱） | 花的甘み・トンカの相方 |
| **マデイラ・レデュクション** | **5 ml**（生マデイラ 15ml を 1/3量に煮詰めたもの） | **マデイラレデュイールソースとの香り連動**・アルコール飛ばし済み |

> **45%生クリーム使用の根拠：** 35%×400ml=140g脂肪 ≒ 45%×130ml=139g脂肪。脂肪バランスを元レシピと同等に保ち、コース全体での重さを管理。
>
> **トンカ豆量の根拠：** 標準パティスリー dose は牛乳1Lに対し 1/2個。300mlで 1/6個が標準だが、**バニラ併用ならしっかり香りを出すため 1/4個**。クマリンの過剰摂取防止のため**1/4個以上は使わない**。

## 工程（約50分・トンカ抽出20分含む）

### Step 0：マデイラ・ミニレデュクション（事前準備・約7分）

トンカ豆インフュージョンと並行で進められる。**アルコールを完全に飛ばし、香りだけ凝縮**する。

1. 小鍋に **マデイラワイン（バーベイト社・スイート）15ml** を入れる
2. **中弱火** で 5-7分静かに煮詰める
3. **1/3量（約 5ml）** まで濃縮する（鍋から離れない・常時揺すり気味）
4. **完全に冷ます**（熱いままアイスに入れると分離・卵黄が固まる）

> **少量レデュクションの注意：**
> - 高糖度のマデイラは煮詰めると激しく泡立つので火力を抑える
> - 1/3量以上煮詰めると苦味・カラメル化リスク
> - **アルコール飛ばしの目的**：純なバニラ＋トンカ味を邪魔せず、マデイラの旨み（チェリー・干しブドウ・木質）だけを凝縮して取り込む

### Step 1：トンカ豆インフュージョン（約25分）

1. トンカ豆 1/4個を **おろし金（マイクロプレーン等）で細かく削る**。包丁で粉末状に刻んでも可
2. 鍋に **牛乳300ml + 砂糖25g**（50gの半分）+ **塩 0.7g** + 削ったトンカ豆を入れる
3. 中火で **70-75℃** まで温める（**沸騰絶対NG**：クマリンが揮発する）
4. ★**火を止めて、フタをして 15-20分 蒸らす**★（低温抽出が最も香り高い）
5. 茶こしで濾す（トンカ粒子を完全除去）→ 牛乳を鍋に戻す

> **20分蒸らし中は手が空く** → 並行で他作業（製麺の加水、メンマの準備など）を進められる。

### Step 2：アングレーズ着火（約15分）

6. 別ボウルで **卵黄3個 + 砂糖25g**（残り半分）を泡立て器で「白っぽくもったり」するまで混ぜる（1-2分）
7. トンカ抽出済み牛乳を再加熱して **60-70℃** まで戻す
8. 温めた牛乳を **3回に分けて** 卵黄ボウルに少しずつ注ぐ（毎回かき混ぜる・テンパリング）
   ※一気に入れると卵がスクランブル化する
9. 全量を鍋に戻し、**弱火** でかき混ぜる
10. 木べらで「8」の字に動かしながら **80℃手前** まで加熱
    - 木べらの背に膜・指で線を引いた跡が残る = 完成
    - **沸騰絶対NG**（80℃超で卵分離）
11. 火を止め、**茶こしで別ボウルに濾す**（凝固した卵粒を除去・滑らかさ保証）

### Step 3：氷水急冷（約10分）

12. 濾したアングレーズを **氷水を張った大きいボウル** にあてて急冷
13. ヘラで時々混ぜながら **20-25℃** まで冷ます
14. 急冷の目的：細菌増殖帯（20-50℃）を素早く通過させる衛生確保

### Step 4：合わせる（約7分）

15. 冷えたアングレーズに以下を加える：
    - **生クリーム45% 130ml**
    - **粉末水あめ 55g**（少しずつ加えて完全に溶かす）
    - **バニラペースト 3g**（小さじ1/2弱）
    - **マデイラ・レデュクション 5ml**（事前に冷ましたもの・Step 0参照）
16. 軽くかき混ぜて均一化（過剰に泡立てない・空気を入れない）
17. 密閉容器に移して **冷蔵庫** へ ★冷凍庫ではない★

### Step 5：冷蔵エイジング（8-10時間）

冷蔵で **一晩寝かせる** ことで以下が起こる：
- 脂肪結晶化が完了し、チャーニング時の安定性UP
- 卵黄の乳化が完了
- トンカ豆・バニラの香りが全体に浸透
- マデイラレデュクションの旨みが馴染む

→ **シャリシャリ抑制と滑らかさを最大化**する最重要工程。

### Step 6：チャーニング（家庭用アイスクリームメーカー・300ml × 2 batches）

家庭用アイスクリームメーカー（**容量約300ml/回**）でチャーニング：

1. アイスクリームメーカー容器は **事前に冷凍庫で 12-24時間** 冷却済みであること
2. 冷蔵庫から混合液を取り出す（**4℃以下の状態**）
3. **1バッチ目（約270ml）** をアイスクリームメーカーに投入→ 20分チャーニング
4. 撹拌完了後、密閉容器に移して **すぐ冷凍庫の最も冷えるところへ**
5. **2バッチ目（約270ml）** を同様にチャーニング → 20分
6. 2バッチ目も同じ容器に合わせて **深冷凍庫** へ
7. 当日まで継続冷凍

### Step 7：当日（D-Day）の準備

- **提供30分前** に冷凍→冷蔵 へ移動（テンパリング・クネル整形しやすい状態に）
- 提供直前に **熱湯に浸したスプーン2本** でクネル整形（50g/個）

## 重要ポイント

| 注意 | 理由 |
|------|------|
| ★ **沸騰絶対NG**（牛乳加熱＋アングレーズ加熱の両方） | 80℃超で卵が分離してスクランブル化、トンカのクマリンも揮発 |
| ★ **3回に分けて牛乳注ぐ（テンパリング）** | 卵黄に直接熱を当てない |
| ★ **必ず濾す（2回：トンカ後＋アングレーズ後）** | 滑らかさの保証 |
| ★ **急冷必須** | 細菌増殖帯を素早く通過、衛生確保 |
| ★ **粉末水あめは冷えたアングレーズに加える** | 結晶化防止に重要・冷えても溶ける |
| ★ **トンカ豆 1/4個以上使わない** | クマリン過剰摂取・苦味リスク |

## クネル提供時のテクニック

1. **提供30分前に冷凍→冷蔵 移動**（柔らかすぎず固すぎず）
2. **クネルスプーン 2本**（または小ぶりの大さじ）を **熱湯に浸して** 使う
3. 1本目で表面をすくい、2本目で押し回しながら整形 → 楕円のクネル
4. **1クネル 約50g**（スプーン山盛り1杯弱）
5. パイ皿の横、**マデイラレデュイールソース** とは別の場所に配置
6. **粉砂糖はパイのみ**（アイスに振ると即溶ける）

## マデイラレデュイールとの相乗効果（コース提案）

トンカ豆を **マデイラレデュイールにも 1/8個** 加えると、**アイスとソースで香りの統一感**が生まれる：

| 要素 | 関連 |
|------|------|
| アイスのバニラ・トンカ | 香りの主柱 |
| ソースのマデイラ・バニラ・トンカ | アイスと共鳴 |
| パイのラズベリー・紅ほっぺ・マデイラ | フルーティな対比 |

→ **トンカ豆を共通アイテムにすることで「コース全体の香りのストーリー」が完成**する。

## トラブルシューティング

| 問題 | 原因 | 対処 |
|------|------|------|
| アングレーズが分離（スクランブル） | 80℃超で加熱しすぎ | 茶こしで濾して粒を除去、それでもダメなら作り直し |
| 苦味が出る | トンカ豆を入れすぎ or 蒸らし時間長すぎ | 次回 1/8個に減らす・蒸らし15分以内 |
| 冷凍後カチカチ | 粉末水あめ不足 or 急冷不十分 | 提供30分以上前にテンパリング |
| ザラザラする | アングレーズ濾しが不十分 / トンカ粒残り | 必ず2回茶こしで濾す |
| 香りが弱い | トンカ豆の削り粗い / 蒸らし短い | 次回はマイクロプレーンで細かく削る・蒸らし20分 |
