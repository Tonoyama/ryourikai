## 共通: 果汁氷の作り方

各ドリンクをそのまま凍らせると糖分で凍りにくいため、以下の手順で氷を作る。

1. 搾汁（または原液）に**水を15%加える**（例: 果汁278ml + 水42ml = 320ml）
2. アイストレーに注ぐ（1トレー27個、320ml）
3. **前々日の夜に仕込む**（凍結まで8〜12時間かかるため）
4. 凍ったらジップロックに移して冷凍庫保管

## 2. 静岡 氷出し一番摘み緑茶

冷水で長時間かけてゆっくり抽出。甘みと旨みが強く、渋みが少ない。

### 手順

1. 茶葉を急須またはポットに入れる
2. 氷と少量の冷水を入れて冷蔵庫で**6〜8時間**抽出
3. 氷が溶けきったら茶葉を濾して提供

---

## 3. 愛媛 完熟レモンの自家製緑茶レモネード

氷出し緑茶をベースに、完熟レモンの酸味とシロップの甘みを合わせた和風レモネード。

### 材料（約2L分）

| 食材 | 分量 |
|------|------|
| 緑茶茶葉（一番摘み） | 15g |
| 水（緑茶抽出用） | 1,200ml |
| 氷（緑茶抽出用） | 適量 |
| 愛媛 完熟レモン | 4〜5個（果汁約150ml） |
| グラニュー糖 | 120g |
| 水（シロップ用） | 120ml |
| レモン輪切り（飾り用） | 6〜8枚 |

### 手順

#### 1. 緑茶ベースを作る（前日）

1. ポットに茶葉15gと氷をたっぷり入れ、冷水1,200mlを注ぐ
2. 冷蔵庫で**8時間以上**かけて氷出し抽出
3. 茶葉を濾す。仕上がり約**1,000ml**

#### 2. レモンシロップを作る

1. グラニュー糖120gと水120mlを小鍋で加熱し、砂糖を完全に溶かす
2. 火を止めて粗熱を取る
3. レモン4〜5個を搾り、果汁約150mlを加えて混ぜる
4. 冷蔵庫で冷やす

#### 3. 合わせる（提供前）

1. 緑茶ベース1,000mlとレモンシロップを合わせる
2. 味見して甘さ・酸味を調整（レモン追加 or シロップ追加）
3. 仕上がり約**1,300〜1,400ml**

#### 4. 提供

1. グラスに緑茶レモネードの氷（共通手順で前々日に仕込み）を入れる
2. レモネードを注ぐ
3. レモンの輪切りを飾る

### 備考

- 氷出し緑茶は渋みが少なく甘みが強いので、レモンの酸味と相性が良い
- 完熟レモンは酸味が穏やかなので、通常のレモンより多めに使ってOK
- レモンの皮もきれいなら輪切りにして飾りに使える（愛媛産はノーワックスが多い）
