# 静岡県産 生茶葉のグラニテ（12人前）

おーいお茶 抹茶入り緑茶（急須タイプ）をベースに、冷蔵生茶葉をダイヤ状に混ぜ込む。フォーク法。

---

## 基本情報

| 項目 | 内容 |
|------|------|
| 提供人数 | 12人 |
| 総液量 | 約555ml |
| 糖度目標 | Brix 10〜11度 |
| 容器 | 深さ2cm程度の浅い容器 |

---

## 材料

| 食材 | 分量 |
|------|------|
| おーいお茶 抹茶入り緑茶（急須タイプ）茶葉 | 9 g |
| 湯（70〜75℃） | 405 ml |
| グラニュー糖 | 45 g |
| 水（シロップ用） | 105 ml |
| レモン果汁 | 27 ml |
| 塩 | 0.3 g |
| 冷蔵生茶葉（手摘み若芽） | 12 g |

---

## 手順

### 1. シロップを作る

水105mlとグラニュー糖45gを小鍋で加熱し、砂糖を完全に溶かす。60℃で止め、粗熱を取る。

### 2. 茶を濃いめに抽出

70〜75℃の湯405mlに茶葉9gを入れ、**1分30秒蒸らす**。すぐに濾す。

### 3. 合わせて冷やす

冷ましたシロップと茶液を合わせ、レモン果汁27mlと塩0.3gを加える。冷蔵庫で**5℃以下**に冷やす。総量約555ml。

### 4. 生茶葉の下処理

1. 1%塩水（水500mlに塩5g）を完全に沸騰させる
2. 生茶葉12gの茎・葉脈を除いた葉のみを投入し、**5〜8秒で引き上げる**
3. 即座に氷水へ30秒
4. キッチンペーパーで水気を完全に拭き取り、**5mm角のダイヤ状**にカットする

> **注意：** 10秒を絶対に超えない。

### 5. 平らな容器で冷凍

液体を深さ2cm程度で浅い容器に流し込み、冷凍庫へ。

### 6. 30分ごとにフォークで掻く

30分ごとに取り出し、フォークで全体を掻き混ぜる。これを**3〜4回繰り返して**シャリシャリの結晶を作る。

### 7. 生茶葉を折り込む

グラニテが半凍り状態（周囲が白く固まり、中央がまだ流動的）になったタイミングでダイヤ状茶葉を加え、フォークで**3〜4回転だけ**軽く折り込む。その後冷凍庫で30〜60分静置して完成。

### 8. 提供直前に仕上げ

冷やしたグラスに盛り付ける。提供直前に生茶葉を1枚指で軽く揉んで添え、香りを立たせる。

---

## 備考

- **塩:** 0.3gに固定。人数が変わっても同量で問題ない
- **塩湯:** 1%濃度（水500mlに塩5g）。人数に関わらず量は変わらない
- **余り:** 冷凍で2〜3日品質維持できる
