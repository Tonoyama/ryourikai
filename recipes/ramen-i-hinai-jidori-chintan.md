## 1. 清湯スープ

### 材料

| 食材 | 分量 |
|------|------|
| 比内地鶏ガラ（背骨・首骨） | 2,700 g（6個） |
| 水 | 5.5 L |
| 長ネギ（青い部分） | 2本 |
| 生姜（薄切り） | 45 g |
| 昆布 | 22 g |

### 工程

**① 鶏ガラの下処理（血抜き）**

1. 鶏ガラを流水で洗い、大きな鍋にガラが浸る程度の冷水を入れ**1時間血抜き**する
2. たっぷりの沸騰湯に投入し1〜2分茹でてから取り出す（霜降り処理）
3. 流水で丁寧に血合いを洗い落とす

**② 清湯スープの抽出（3時間）**

1. 鍋に水5.5Lを入れ、下処理した鶏ガラ・昆布を加えて中火にかける
2. 沸騰直前（80〜85℃）になったら**昆布を取り出す**
3. **絶対に沸騰させず**、表面がかすかに揺れる「ぬる湯」状態（85〜90℃）を維持する
4. 長ネギ（青い部分）・生姜を加え、アクを丁寧に除去しながら**3時間抽出**する
5. 透き通った琥珀色の清湯に仕上げる

> **ポイント：** 比内地鶏は脂が上品なため、沸騰させなくても十分な旨みが出る。沸騰させると濁りの原因になるため温度管理が最重要。

**③ 濾過・仕上げ**

1. 抽出したスープを細目のシノワ（または二重にしたガーゼ）で静かに濾す
2. **絞らず**、重力だけで自然に落とす（透明度を保つため）
3. 仕上がり目標：約**2.5〜3.0 L**（Brix 3〜4程度）
4. 冷蔵で一晩置くと脂が固まり、より澄んだスープになる

> **収支：** 必要量1,800ml（150ml × 12杯）に対し余裕を持って対応可能。

## 2. 清湯タレ

| 濃口醤油 | 30 ml |
| みりん | 60 ml |
| 日本酒 | 60 ml |

### 工程

4. 冷ましてから保存容器に移す

> **使用量の目安：** 丼1杯に対して25〜30 ml

## 3. 自家製平打ち麺（ブレンド粉）

### 材料

| 食材 | 分量 |
|------|------|
| 特ナンバーワン（準強力粉・日清製粉）70% | **700 g**（12人前420g→20人前換算） |
| 飛行船（春よ恋100%・強力粉）30% | **300 g**（12人前180g→20人前換算） |
| 水（製麺用） | **430 ml** |
| かん水 | **10 g** |
| 塩（製麺用） | **10 g** |
| 乾燥卵白 | **10 g** |

> **加水率：43%　/　1杯あたり麺量：約50g　/　20人前仕様（試作・茹でロス・バッファ込み）**
> 麺だけ20人前に増量。スープ・トッピング・タレは12人前のまま。

### ブレンド意図

- **特ナンバーワン**（タンパク11.2%・灰分0.34%）: 中華麺用設計の白く繊細な準強力粉。清湯スープの透明感を邪魔せず、扱いやすさで失敗確率を下げる
- **飛行船**（春よ恋100%・タンパク11.2%・灰分0.40%）: 北海道産の華やかな香りと甘み、もちもち感を加える
- 春よ恋単一だと粘性が強く製麺難度が高く、色も黄色寄りになるため、準強力粉でブレンドして清湯映えする白い麺に仕上げる

### 工程

1. かん水・塩を水に溶かす
2. 特ナンバーワンと飛行船、乾燥卵白をふるってよく混ぜておく
3. 少しずつ加水しながら混ぜ、生地をまとめる
4. ビニール袋に入れて踏み、**15分休ませる** → これを3回繰り返す
5. しっかりとしたコシのある生地に仕上げる
6. 製麺機（または麺棒）で**厚さ1mm**に伸ばす
7. **幅3.5mm**の平打ち麺にカットする
8. 打ち粉をして冷蔵で**30分以上休ませる**

> **ポイント：** 春よ恋の甘みを活かすため、かん水量を最小限に抑える。平打ちにすることでスープの持ち上がりが向上する。

## 5. 豚モモ 和風コンフィ

### 材料

| 食材 | 分量 |
|------|------|
| 豚モモ肉（ブロック） | 1,200 g |
| 菜種油（コンフィ用） | 600 ml |
| 醤油（コンフィ用） | 60 ml |
| みりん（コンフィ用） | 40 ml |
| 日本酒（コンフィ用） | 40 ml |
| にんにく（コンフィ用） | 4片 |
| タイム・ローリエ（コンフィ用） | 各4本 |

### 工程

**前日仕込み**

1. 豚モモに塩（肉の1.5% = 約18g）をすり込み、ラップで包んで**冷蔵庫で一晩置く**

**当日コンフィ**

1. 鍋に菜種油・醤油・みりん・日本酒・にんにく・タイム・ローリエを入れ**80℃に温める**
2. 豚モモを投入し、**80℃を保ちながら2時間コンフィ**にする
3. そのまま冷ましてオイルに漬けたまま冷蔵保存

**提供直前**

1. スライスしてバーナーで表面を焦がし、香りと焼き色をつける

> **ポイント：** 醤油・みりん・日本酒を加えることで和風の甘辛い香りがコンフィオイルに溶け込み、比内地鶏の清湯と調和する。

## 6. 自家製鶏油（山椒鶏油）

### 材料

| 食材 | 分量 |
|------|------|
| 比内地鶏の脂（腹腔内脂肪・皮） | 300 g |
| 水（精製用） | 75 ml |
| **実山椒** | **8 g**（油への浸出用・**塩漬けの場合は塩抜きしてから使用**） |

### 工程

**山椒鶏油の精製（水煉り法 + 実山椒浸出）**

1. 比内地鶏の脂を小鍋に入れ、水75mlを加えて弱火にかける
2. 水分が完全に蒸発するまでゆっくりと脂を溶かし出す
3. 脂が透き通ったクリアな黄金色になったら、**火を弱火のまま実山椒8gを投入**
4. **弱火で5〜8分浸出**（沸騰させず、油の中で実山椒の香りがゆっくり立ち上がるくらい）
5. 細目のシノワで濾す（実山椒は取り除く・**香りが油に移っていればOK**）
6. 目標量：約**150〜180 ml**

> **保存：** 冷蔵で最大5日。
>
> **山椒浸出のコツ：** 沸騰させない（焦がすと苦味だけが残る）。弱火で 5〜8分が黄金時間。香りが立ったら即火を止めて濾す。
>
> **実山椒の形態別注意：**
> - 生 実山椒：そのまま投入可、香り最強
> - 塩漬け：**冷水に10分浸して塩抜き**→水気をしっかり拭いてから投入
> - 冷凍生実山椒：解凍後そのまま投入
> - 醤油漬け・佃煮：**油浸出には不向き**（醤油・砂糖が油に混入するため）→ トッピング用のみに転用

## 7. 茨城産 夏長ネギの焼き

### 材料

| 食材 | 分量 |
|------|------|
| 茨城産夏長ネギ（白い部分のみ） | 12本 |

### 工程

1. 長ネギを**5〜6cmの長さ**に切る
2. 鉄製スキレットまたは直火で**しっかり焼き色をつける**（全面炭化一歩手前まで）
3. 芯まで火が通り、甘みが増した状態に仕上げる

> **提供直前に焼くのがベスト。** 茨城産の夏長ネギは水分が多く甘みが強い。焼くことで糖度が増し、清湯の上品な旨みに焦げの複雑さが加わる。

## 8. 穂先メンマの味付け（清湯版）

水煮1kg のうち **500g を清湯版**として味付ける（残り500gは豚骨版＝Ramen IIへ）。
**12人前(360g)＋お土産(140g)** に分ける。比内地鶏とアサリの清湯に合わせるため、**色を出さず、貝旨み × 魚醤 × 鶏清湯の三層構造**で設計。ごま油は使わず、鶏油（チー油）に油脂層を任せる。

### 材料（500g）

| 食材 | 分量 | 役割 |
|------|------|------|
| 穂先メンマ（水煮） | 500 g | 12人前(360g) + お土産(140g) |
| 梶田商店 巽 淡口（天然醸造・丸大豆・愛媛産・無添加） | 25 ml | 主柱：色を抑えつつ天然醸造の旨み（**食塩相当量 18g/100ml ≒ 15% w/w**、25ml = 塩分4.5g、標準淡口より6%低塩） |
| 日東醸造 足助仕込三河しろたまり | 10 ml | 副：麦由来の淡い旨みと上品な香り |
| まるはら 鮎魚醤 | 3 ml | 隠し味：**アサリ・比内地鶏とシナジー**（清湯版こそ魚醤が活きる） |
| 福光屋 福みりん（純米本みりん・3年熟成） | 25 ml | 上品な甘み・3年熟成の複雑な旨み（**焦げやすいので火加減控えめ**） |
| 日本酒 | 25 ml | 鶏との相性◎ |
| 砂糖 | 3 g | 極控えめ（福みりんの糖度が高いため） |
| 鶏清湯 or 昆布水 | 50 ml | 出汁の連続性（清湯と同じ味の系で煮る） |
| 生姜薄切り | 1枚 | 控えめに |
| 柚子皮（任意） | ひとつまみ | 仕上げ香 |
| ごま油 | **使わない** | 鶏油に油脂層を任せる |

### 工程

1. 水煮メンマをザルにあけて水気を切り、流水で軽くすすぐ
2. 1〜2分下茹でして水煮臭抜き → ザルでしっかり水気切る
3. 鍋にメンマと生姜を入れ、中火で**空炒り（油なし）2分**（水分を飛ばす）
4. みりん＋日本酒を加え、中火で1〜2分（アルコール飛ばし）
5. 巽 淡口＋白たまり＋鮎魚醤＋砂糖＋鶏清湯(または昆布水) を加える（**福みりんは焦げやすいのでこの時点で火加減を中弱に**）
6. **弱火**で汁気が半分残る程度（5〜7分）まで静かに**煮含める**
   ※豚骨版より「煮絡め」より「煮含め」寄り。色を出さないため強火NG
7. 火を止め、生姜を取り除く
8. 任意で柚子皮を擦って香りを移す
9. 粗熱を取る → 12人前(360g)用と お土産用(140g)用に分けて密閉容器で冷蔵 → **一晩寝かせる**
10. 提供時に小鍋で温め直す（汁気と共に）

### 味の設計意図

| 層 | 担当 | 役割 |
|----|------|------|
| 第1層（土台の塩味＋天然醸造の旨み） | 梶田商店 巽 淡口 | 軽い塩味で清湯の透明感を保ちつつ、天然醸造1年熟成の旨み層を追加 |
| 第2層（上品な旨み） | 日東醸造 しろたまり | 麦と大豆由来の淡色旨み |
| 第3層（奥行き） | 鮎魚醤 | **アサリの貝旨みと相乗**、鶏清湯にも溶け込む |
| 甘み | 福光屋 福みりん＋砂糖（極控えめ） | 3年熟成純米本みりんの複雑な甘みが主、砂糖は輪郭のみ |
| 香り | 柚子皮（任意） | 清涼感を添える |
| 油脂層 | 鶏油（外部担当） | メンマ自体には油を入れない |

> **巽 淡口＋白たまりを使う理由：** 清湯の透明感を保ちつつ旨みを足す。再仕込＋溜（豚骨版）と真逆の設計。巽は天然醸造1年熟成・丸大豆・愛媛産・無添加・木樽醸造で、一般薄口より旨み層が厚い（公式説明：「薄口の塩辛さが目立つ通常品と違い、巽濃口の旨味と淡い色を両立」）。**食塩相当量18g/100ml（15% w/w）の実測値**で、標準淡口（16% w/w）より約6%低塩。**他のレシピと同量で安全に置換可能**、むしろ低塩化により白たまり・鮎魚醤・福みりんの旨み層がより映える。
>
> **福光屋 福みりん（3年熟成純米本みりん）を使う理由：** もち米・米麹・米焼酎を3年熟成した純米仕様で、糖の熟成度が一般本みりんより高い。複雑な甘みとアミノ酸の旨みでメンマの味に層を作る。**焦げやすいので投入後の火加減は中弱以下**。
>
> **ごま油を抜く理由：** 清湯ラーメンの油は鶏油（チー油）が担当する。メンマからもごま油の香りが立つと、鶏とアサリの繊細な香りを覆い隠す。
>
> **鶏清湯を煮汁に使う理由：** 仕上がりが清湯スープの味の系内に収まる。同じ味のレイヤーで重ねるとプロっぽい一体感が出る。手元に清湯スープ（作成済み・冷蔵中）があるので、50ml だけ取り分けて使う。
>
> **アサリ清湯との相性：** 鮎魚醤の発酵旨みとアサリの貝旨みは「魚介の旨み」というカテゴリで親和性が高い。豚骨版より清湯版の方が鮎魚醤が活きる。

## 9. 仕上げ・盛り付け

### 当日の作業タイムライン

| タイミング | 作業 |
|-----------|------|
| 提供30分前 | 清湯スープを加熱（85℃を維持） |
| 提供15分前 | 豚モモコンフィをスライス・バーナーで炙り |
| 提供10分前 | 長ネギを焼く |
| 提供5分前 | 雲吞・麺を茹でる |
| 提供直前 | タレ投入 → スープ → 盛り付け → 鶏油 |

### 盛り付け手順（1杯あたり）

1. 温めた丼に**タレ25〜30ml**を入れる
2. 清湯スープ（**150ml**・比内地鶏清湯 + アサリ清湯 合わせ）を静かに注ぐ
3. 湯切りした**平打ち麺（約50g）を中央に盛る**
4. 雲吞・豚モモコンフィ・焼き長ネギを美しく配置する
5. **穂先メンマ清湯版**（巽淡口・白たまり・鮎魚醤・福みりん仕様）を 穂先1〜2本そのまま添える
6. **山椒鶏油を小さじ1（4〜5ml）** スープ表面にそっと垂らす
7. **実山椒 2〜3粒** をスープ表面に**潰さずに**そっと浮かべる（飾り・香りの瞬間アクセント）

> **実山椒トッピングを潰さない理由：** 潰すと一気に山椒油・サンショオール成分が広がり、繊細な清湯の輪郭が消える。**粒のまま** 浮かべることで、食べる人が口に入れた時にじんわり香りが立ち、コース後半の山椒の余韻を作る。視覚的にも緑の点が清湯の透明感に映える。
