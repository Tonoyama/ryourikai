## 1. 清湯スープ

### 材料

| 食材 | 分量 |
|------|------|
| 比内地鶏ガラ（背骨・首骨） | 2,700 g（6個） |
| 水 | 5.5 L |
| 長ネギ（青い部分） | 2本 |
| 生姜（薄切り） | 45 g |
| 昆布 | 22 g |

### 工程

**① 鶏ガラの下処理（血抜き）**

1. 鶏ガラを流水で洗い、大きな鍋にガラが浸る程度の冷水を入れ**1時間血抜き**する
2. たっぷりの沸騰湯に投入し1〜2分茹でてから取り出す（霜降り処理）
3. 流水で丁寧に血合いを洗い落とす

**② 清湯スープの抽出（3時間）**

1. 鍋に水5.5Lを入れ、下処理した鶏ガラ・昆布を加えて中火にかける
2. 沸騰直前（80〜85℃）になったら**昆布を取り出す**
3. **絶対に沸騰させず**、表面がかすかに揺れる「ぬる湯」状態（85〜90℃）を維持する
4. 長ネギ（青い部分）・生姜を加え、アクを丁寧に除去しながら**3時間抽出**する
5. 透き通った琥珀色の清湯に仕上げる

> **ポイント：** 比内地鶏は脂が上品なため、沸騰させなくても十分な旨みが出る。沸騰させると濁りの原因になるため温度管理が最重要。

**③ 濾過・仕上げ**

1. 抽出したスープを細目のシノワ（または二重にしたガーゼ）で静かに濾す
2. **絞らず**、重力だけで自然に落とす（透明度を保つため）
3. 仕上がり目標：約**2.5〜3.0 L**（Brix 3〜4程度）
4. 冷蔵で一晩置くと脂が固まり、より澄んだスープになる

> **収支：** 必要量1,800ml（150ml × 12杯）に対し余裕を持って対応可能。

## 2. 清湯タレ

### 材料

| 食材 | 分量 |
|------|------|
| 薄口醤油 | 90 ml |
| 濃口醤油 | 30 ml |
| みりん | 60 ml |
| 日本酒 | 60 ml |
| 昆布水（タレ用） | 60 ml |

### 工程

1. みりん・日本酒を小鍋に入れ弱火でアルコールを飛ばす
2. 薄口醤油・濃口醤油を加えて一度温める
3. 昆布水を加えて混ぜ合わせる
4. 冷ましてから保存容器に移す

> **使用量の目安：** 丼1杯に対して25〜30 ml

## 3. 春よ恋 自家製平打ち麺

### 材料

| 食材 | 分量 |
|------|------|
| 春よ恋（強力粉） | 600 g |
| 水（製麺用） | 258 ml |
| かん水 | 6 g |
| 塩（製麺用） | 6 g |
| 乾燥卵白 | 6 g |

> **加水率：43%　/　1杯あたり麺量：約50g**

### 工程

1. かん水・塩を水に溶かす
2. 春よ恋と乾燥卵白をふるって混ぜておく
3. 少しずつ加水しながら混ぜ、生地をまとめる
3. ビニール袋に入れて踏み、**15分休ませる** → これを3回繰り返す
4. しっかりとしたコシのある生地に仕上げる
5. 製麺機（または麺棒）で**厚さ1mm**に伸ばす
6. **幅3.5mm**の平打ち麺にカットする
7. 打ち粉をして冷蔵で**30分以上休ませる**

> **ポイント：** 春よ恋本来の甘みを活かすため、かん水量を最小限に抑える。平打ちにすることでスープの持ち上がりが向上する。

## 4. 比内地鶏 雲吞

### 材料

| 食材 | 分量 |
|------|------|
| 比内地鶏むね肉（雲吞用） | 450 g |
| 比内地鶏皮（雲吞用） | 90 g |
| 生姜（おろし・雲吞用） | 15 g |
| 長ネギ（みじん切り・雲吞用） | 60 g |
| 薄口醤油（雲吞用） | 小さじ3 |
| ごま油（雲吞用） | 小さじ3 |
| 片栗粉（雲吞用） | 小さじ3 |
| 雲吞皮（市販） | 60枚 |

> **1人あたり5個**

### 工程

1. むね肉と皮を包丁でたたき、粗めのミンチにする
2. 生姜・長ネギ・薄口醤油・ごま油・片栗粉を加えてよく混ぜ、**粘りが出るまで練る**
3. 雲吞皮に少量包んで包む（5個/人分）
4. 茹でる直前まで冷蔵保存

## 5. 豚モモ 和風コンフィ

### 材料

| 食材 | 分量 |
|------|------|
| 豚モモ肉（ブロック） | 1,200 g |
| 菜種油（コンフィ用） | 600 ml |
| 醤油（コンフィ用） | 60 ml |
| みりん（コンフィ用） | 40 ml |
| 日本酒（コンフィ用） | 40 ml |
| にんにく（コンフィ用） | 4片 |
| タイム・ローリエ（コンフィ用） | 各4本 |

### 工程

**前日仕込み**

1. 豚モモに塩（肉の1.5% = 約18g）をすり込み、ラップで包んで**冷蔵庫で一晩置く**

**当日コンフィ**

1. 鍋に菜種油・醤油・みりん・日本酒・にんにく・タイム・ローリエを入れ**80℃に温める**
2. 豚モモを投入し、**80℃を保ちながら2時間コンフィ**にする
3. そのまま冷ましてオイルに漬けたまま冷蔵保存

**提供直前**

1. スライスしてバーナーで表面を焦がし、香りと焼き色をつける

> **ポイント：** 醤油・みりん・日本酒を加えることで和風の甘辛い香りがコンフィオイルに溶け込み、比内地鶏の清湯と調和する。

## 6. 自家製鶏油

### 材料

| 食材 | 分量 |
|------|------|
| 比内地鶏の脂（腹腔内脂肪・皮） | 300 g |
| 水（精製用） | 75 ml |

### 工程

**鶏油の精製（水煉り法）**

1. 比内地鶏の脂を小鍋に入れ、水75mlを加えて弱火にかける
2. 水分が完全に蒸発するまでゆっくりと脂を溶かし出す
3. 脂が透き通ったクリアな黄金色になったら細目のシノワで濾す
4. 目標量：約**150〜180 ml**

> **保存：** 冷蔵で最大5日。

## 7. 茨城産 夏長ネギの焼き

### 材料

| 食材 | 分量 |
|------|------|
| 茨城産夏長ネギ（白い部分のみ） | 12本 |

### 工程

1. 長ネギを**5〜6cmの長さ**に切る
2. 鉄製スキレットまたは直火で**しっかり焼き色をつける**（全面炭化一歩手前まで）
3. 芯まで火が通り、甘みが増した状態に仕上げる

> **提供直前に焼くのがベスト。** 茨城産の夏長ネギは水分が多く甘みが強い。焼くことで糖度が増し、清湯の上品な旨みに焦げの複雑さが加わる。

## 8. 仕上げ・盛り付け

### 当日の作業タイムライン

| タイミング | 作業 |
|-----------|------|
| 提供30分前 | 清湯スープを加熱（85℃を維持） |
| 提供15分前 | 豚モモコンフィをスライス・バーナーで炙り |
| 提供10分前 | 長ネギを焼く |
| 提供5分前 | 雲吞・麺を茹でる |
| 提供直前 | タレ投入 → スープ → 盛り付け → 鶏油 |

### 盛り付け手順（1杯あたり）

1. 温めた丼に**タレ25〜30ml**を入れる
2. 清湯スープ（**150ml**）を静かに注ぐ
3. 湯切りした**平打ち麺（約50g）を中央に盛る**
4. 雲吞・豚モモコンフィ・焼き長ネギを美しく配置する
5. **自家製鶏油を小さじ1（4〜5ml）** スープ表面にそっと垂らす
