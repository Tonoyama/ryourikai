## 1. 呼び戻し豚骨スープ

### スープの収支

| 項目 | 量 |
|------|------|
| 既存スープ（旧ダシ・抽出済み） | 2,000 ml |
| 追加ゲンコツ（新規炊き出し） | 4,000 g |
| 炊き出し用水 | 5.0 L |
| 新スープ仕上がり目標 | 約2.5 L |
| 呼び戻し合計 | 約4〜4.5 L |
| 必要量（150ml × 12杯） | 1,800 ml |

> **呼び戻しとは：** 久留米ラーメン発祥の技法。旧スープに新しく炊いたスープを継ぎ足すことで旨みが幾重にも重なる。翌日以降も残ったスープを継ぎ足すことでさらに旨みが深まる。

### 材料

| 食材 | 分量 |
|------|------|
| 豚ゲンコツ（追加・呼び戻し用） | 4,000 g |
| 水（炊き出し用） | 5.0 L |

### 工程

**① 豚ゲンコツの下処理（前日）**

1. ゲンコツを流水で洗い、大きな鍋にたっぷりの冷水を入れ**2時間血抜き**する
2. たっぷりの沸騰湯に投入し**5〜10分茹でてから取り出す**（霜降り処理）
3. 流水でぬめりと血合いをブラシで丁寧に洗い落とす
4. ゲンコツは割って**骨髄が出やすい状態**にしておく

**② 呼び戻しスープの炊き出し（強火・8〜12時間）**

1. 大鍋に下処理したゲンコツと水5.0Lを入れ、最初は**強火で沸騰させる**
2. 沸騰後も**あえて強火を維持**し、白濁した超濃厚スープに仕上げる（久留米系は濁りを恐れない）
3. 途中、蒸発した分だけ湯を足しながら**8〜12時間炊き続ける**
4. 脂とコラーゲンが完全に乳化し、どろっとした超濃厚スープに仕上げる
5. 仕上がり目標：約**2.5L**

**③ 呼び戻しスープの合わせ**

1. 炊き上がった新スープを細目のシノワで濾す
2. 既存の旧スープ（2,000ml）と新スープを鍋に合わせ、弱火でゆっくり混ぜ合わせる
3. 合計約4〜4.5Lを目標とする
4. 使う分だけ都度温め、残りは冷蔵保存（翌日以降もさらに旨みが増す）

## 3. 自家製家系中太麺（ブレンド粉・ATLAS 150仕様）

### 材料（家系仕様）

| 食材 | 分量 |
|------|------|
| 特飛龍（準強力粉・日清製粉）60% | **720 g**（12人前432g→20人前換算） |
| 勇（準強力粉・熊本製粉）40% | **480 g**（12人前288g→20人前換算） |
| 水（製麺用・冷水5℃前後） | **396 ml**（**33%加水**） |
| かん水 | **12 g** |
| 塩（製麺用） | **12 g** |
| 乾燥卵白 | **17 g** |

> **加水率：33%（家系仕様・低加水）　/　1杯あたり麺量：約60g　/　20人前仕様（試作・茹でロス・バッファ込み）**
> **切断：ATLAS 150 の 1mm カッター　/　麺帯厚み：2mm（通常0.8-1mm を倍に厚く）**
> 麺だけ20人前に増量。スープ・トッピング・タレは12人前のまま。

### ブレンド意図

- **特飛龍**（タンパク10.8%・灰分0.35%）: 製麺機に通しやすく、麺帯が裂けにくい
- **勇**（タンパク13.0%・灰分0.42%）: 強い粉。**歯切れと骨格・グニグニした食感**をつくる
- 低加水家系仕様では **勇の蛋白質が骨格** を作るので、ブレンド比率はそのまま維持

### なぜ加水率33%か（家系仕様）

家系ラーメンの本質は **低加水ストレート中太麺のグニグニ感**。家系の聖地・吉村家・酒井製麺所の麺は **加水率30-35%** が標準。低加水ほど：
- 噛みごたえが強い（歯切れ＝家系らしさ）
- スープと絡みやすい（吸い込み力）
- 茹で時間が長くなる（1分30秒〜2分）

→ **33%が家系の定番ライン**。これ以下は粉がまとまらず製麺機通過困難。

### 麺帯を厚く保つ理由

通常の細麺は0.8-1mm厚で薄く伸ばすが、家系は **2mm厚** で止めることで：
- 切断幅1mm × 厚み2mm = **断面が縦長の四角**
- 結果：中太の食感（実質的に1.5-2mm相当の家系太麺）
- ATLAS 150の標準カッター（1mm/3.5mm/5mm）の中で家系に最も近い再現方法

### 工程

**① 加水（分割・3回）**

1. かん水・塩を冷水（5℃前後）に完全に溶かす
2. 特飛龍・勇・乾燥卵白をふるってよく混ぜておく
3. ボウルに入れ、塩水を**3回に分けて**少しずつ加える
3. そのたびほぐすようにまんべんなく混ぜ、全体に湿気が行き渡ったら次の加水へ
4. 最後は手で押しまとめる程度で止める（練りすぎない）

**② 初回休眠（冷蔵・30分）**

1. 生地をビニール袋に入れ、空気を抜いて密閉する
2. **踏まずそのまま冷蔵庫に30分以上休ませる**
3. 少ない水分を粉全体に均一に浸透させるための重要な工程

**③ 踏み・休ませのサイクル（3回繰り返す）**

1. 冷蔵庫から出して平らな場所で**足で踏む**
2. 生地を広げて一度踏んだら二つ折りにしてまた踏む → 4〜5回繰り返す
3. 生地がまとまってきたら再度ビニール袋に入れ、**冷蔵庫に15分休ませる**
4. このサイクル（踏み→冷蔵休）を**3回**繰り返す

**④ 最終休眠（冷蔵・1時間以上）**

1. 最後の踏み後、ビニール袋に入れたまま**冷蔵庫に1時間以上寝かせる**
2. 生地の跡が出て裂けなくなれば成功

**⑤ ATLAS 150での延び伸ばし**

1. ダイヤル1（最厚）から引き始め、**2→3→4→5→6→7**の順に段階的に伸ばす
2. 各ダイヤルで少なくとも**2回通す**こと（一気に薄くするとグルテンが切れる）
3. ダイヤル6〜7仕上げで**端材を実測して厚さ1.2mmに調整**する
4. 勇のタンパク13.0%により弾力が強く、伸ばした直後に若干縮むため、少し薄めに仕上げる意識で伸ばす

**⑥ 1mmカッターでカット・保存**

1. 打ち粉（サンカラットSGM）を充分にまぶしてからカッターに通す
2. カット後すぐに麺をほぐしてだんごに丸め、打ち粉をまぶして冷蔵保存
3. 1杯あたり約**60g**

**⑦ 茹で時間**

1. たっぷりの沸騰湯（塩なし）で**45秒〜1分**茹でる
2. 濃厚スープによく絡むよう、**芯が残る程度（やや硬め）**で湯切りする
3. 湯切りはしっかり行い、スープが薄まらないようにする

## 4. 米沢豚バラ 三温糖キャラメリゼ焼豚

### 材料

| 食材 | 分量 |
|------|------|
| 米沢豚バラ肉（ブロック） | 1,500 g |
| 三温糖（キャラメリゼ用） | 60 g |
| **キッコーマン 特選 丸大豆醤油**（メイン・濃口） | 100 ml |
| **湯浅醤油（再仕込・小原久吉商店）**（コク・深み） | 50 ml |
| **福光屋 福みりん**（純米本みりん・3年熟成） | 100 ml |
| 日本酒（純米酒推奨） | 100 ml |
| 長ネギ（青い部分・煮豚用） | 1本 |
| 生姜（薄切り・煮豚用） | 20 g |

> **醤油の使い分け：**
> - **キッコーマン特選 丸大豆（メイン100ml）**：濃口醤油の標準・骨格を作る
> - **湯浅再仕込（50ml）**：再仕込み由来のコク・**煮汁が深まる**ので **タレ・味玉ダレへの流用効果が大幅UP**
> - 計150mlの構成は変えずに、**ブレンド比率で煮汁の質を一気に格上げ**できる
>
> **福みりん使用の根拠：**
> - 3年熟成・純米仕様で**糖の複雑性が高い**
> - 焼豚の三温糖キャラメリゼと相乗して**多層の甘み**を作る
> - 焼豚煮汁経由でタレ・味玉にも影響するので**コース全体の旨み統一感**が出る
> - **焦げやすいので火加減控えめ**（家系では弱中火維持）

### 工程

**前日仕込み**

1. 豚バラを巻いてタコ糸で縛り、**表面の水分をキッチンペーパーでしっかり拭き取る**（水分が残ると熱い糖が跳ねる・焼き色もつきにくい）
2. フライパンを **中火〜中強火** で熱し、**三温糖60gを広げて入れる**（必要なら **水大さじ1-2** を加えてウェットキャラメル化・焦げ防止）
3. 三温糖が溶けて **薄い琥珀色** になったら火を少し弱め、豚バラを入れて表面全体に絡めながら焼き色をつける。**黒くなり始めたら即火を止める**（焦げると煮汁全体に苦味が移る・致命的）
4. 鍋に移し、酒100ml+みりん100mlを**一度沸かしてアルコール飛ばし**（任意・酒臭さ防止）→ キッコーマン100ml + 湯浅50ml + 長ネギ・生姜を加える
5. **水を700-1,000ml** 程度、肉が **8〜9割浸かる** くらいまで加える
6. 落とし蓋をして、**煮汁がふつふつする程度の弱火**（沸騰させない・肉が締まらない・脂が荒く溶けない）で **90〜120分** 煮る
7. **煮込み開始から45〜60分で一度上下を返す**（味ムラ防止）
8. 火を止め、**粗熱を取ってから** 保存容器に移し、肉と煮汁を分けずに一晩冷蔵（冷蔵庫の温度上昇・衛生面の配慮）

**翌日朝**

1. 煮汁表面に **固まった脂を取り分ける**（捨てない・**香味油としてラーメンに使える**）
2. 煮汁を **濾して**（長ネギ・生姜カスを除去）→ タレ100ml・味玉ダレ150ml に分配
3. **タレに使う場合は煮汁を 2-3割 煮詰めて濃度調整**（薄ければ追加で煮詰め）

**提供直前**

1. 豚バラを好みの厚さにスライス
2. バーナーで表面を炙る（脂が少し溶け香ばしさが立つ）

> **三温糖キャラメリゼの安全策：**
> - **強火 → 中火〜中強火** に変更（焦げのリスクを大幅に減らす）
> - **ウェットキャラメル**（水大さじ1-2追加）で失敗しにくい・初心者向け
> - 目標は **薄い琥珀色〜やや濃い琥珀色**。黒くなったら完全にやりすぎ
> - 焦げると **香ばしさではなく苦味** になり、煮汁経由でタレ・味玉まで台無しになる
>
> **煮込み温度の重要性：**
> - **ぐらぐら沸かさない**（沸騰は肉が締まる・脂が荒く溶ける）
> - **ふつふつ程度（85-90℃）** を維持
> - 90分でしっかりスライス向き、120分で柔らかめ
>
> **冷蔵後の脂の活用：**
> - 表面の固まった脂は **ラーメンに使える香味油**
> - 焼豚エキスとキャラメル香が凝縮している
> - Ramen II の鶏油と並ぶ **二次香味油** として提供時にスープ表面に少量垂らすと格上げ

## 5. 味玉

### 材料

| 食材 | 分量 |
|------|------|
| 卵 | 12個 |
| 焼豚の煮汁（味玉漬けダレ用） | 150 ml |
| 水（漬けダレ希釈用） | 100 ml |

### 工程

1. 卵を沸騰湯に静かに入れ**7分茹でる**
2. 冷水に取って殻をむく
3. 焼豚の煮汁150mlを水100mlで希釈して漬けダレを作る
4. 卵を袋に入れて漬けダレに浸す
5. 冷蔵で**最低12時間以上漬け込む**（24時間漬けると色・味ともにより深くなる）
6. 提供時は半分にカットして断面を見せる

> **焼豚の煮汁を使う理由：** スープ・タレ・焼豚・味玉が同じ煮汁でつながることで、一杯全体に統一感と奥行きが生まれる。

## 6. 穂先メンマの味付け（豚骨版・500g）

水煮1kg のうち **500g を豚骨版**として味付ける（残り500gは清湯版＝Ramen Iへ）。
**12人前(360g)＋お土産(140g)** に分ける。多層の醤油＋本みりんで豚骨スープと焼豚の濃厚さに負けない上品な旨みを構成。**水分追加・ごま油2段使い・一晩寝かせ**で味の浸透と落ち着きを確保。

### 材料（500g）

| 食材 | 分量 | 役割 |
|------|------|------|
| 穂先メンマ（水煮） | 500 g | 12人前(360g) + お土産(140g) |
| 湯浅醤油（再仕込・小原久吉商店） | 25 ml | 主柱：再仕込のコクで豚骨と拮抗 |
| 傳右衛門 溜 | 7 ml | 副：旨みの厚みと色付け（控えめ） |
| まるはら 鮎魚醤 | 3 ml | 隠し味：魚介の旨み（**入れすぎ厳禁** ） |
| 福光屋 福みりん（純米本みりん・3年熟成） | 20 ml | 上品な甘み・複雑な旨み・照り（普通の本みりんより糖の熟成度高い→**焦げやすい注意**） |
| 日本酒 | 20 ml | 臭み消し・旨み |
| 砂糖 | 6 g | 甘味の輪郭補強（福みりん使う分は据え置き） |
| ごま油 | 5 ml + 10 ml | 炒め用＋仕上げ用に分割 |
| 生姜薄切り | 2枚 | 香り（最後に取り除く） |
| 水 or 鶏清湯 | 30〜50 ml | 500gに均一に味を入れる必須水分 |

### 工程

1. 水煮メンマをザルにあけて水気を切り、流水で軽くすすぐ
2. 1〜2分下茹でして水煮臭抜き → ザルでしっかり水気切る
3. 鍋に **ごま油5ml** と 生姜を入れ中火で香り出し
4. メンマ投入し、水分を飛ばすように2〜3分炒める
5. みりん＋日本酒を加え、中火で1〜2分（アルコール飛ばし）
6. 湯浅醤油＋傳右衛門溜＋鮎魚醤＋砂糖＋水(または鶏清湯)を加える
7. 弱〜中火で汁気が少し残る程度（5〜7分）まで煮詰める（**煮詰めすぎ厳禁**：穂先のやわらかさが死ぬ）
8. 火を止め、**仕上げのごま油10ml** を回しかけて絡める
9. 生姜を取り除く
10. 粗熱を取る → 12人前(360g)用と お土産用(140g)用に分けて密閉容器で冷蔵 → **一晩寝かせる**（角が取れて味が落ち着く）
11. 提供時に小鍋で温め直す（汁気と共に）

### 味の設計意図

| 層 | 担当 | 役割 |
|----|------|------|
| 第1層（土台の塩味＋旨み） | 湯浅再仕込 | 醤油の主柱。再仕込で長期熟成由来のコク |
| 第2層（旨みの厚み） | 傳右衛門溜 | 大豆主体の濃い旨みで豚骨に拮抗 |
| 第3層（奥行き） | 鮎魚醤 | 魚介の隠し味。豚骨スープにも合う方向性 |
| 甘味 | 本みりん＋砂糖 | みりんで上品さ、砂糖でキレ |
| 香り | ごま油＋生姜 | 油脂と清涼感 |

> **穂先メンマをそのまま使う理由：** 細切りにすると食感がほぼなくなる。穂先1〜2本をそのまま乗せることでやわらかさがコース仕様の上品さと合い、焼豚との食感の対比も出る。
>
> **白たまり・薄口を使わない理由：** 色が薄すぎてメンマの「見た目の存在感」が出ない。再仕込＋溜で色を入れた方が丼の中で映える。
>
> **金笛 再仕込み生醤油を選ばない理由：** 生醤油は加熱で香りが飛ぶ。絡め系には湯浅、生醤油は仕上げ用に温存。
>
> **水/鶏清湯を加える理由：** 水分なしだと「醤油ダレを表面に絡める」状態になり、500g 全体に均一な味浸透が難しい。少量の水分でメンマ繊維に味を入れる。

## 7. 茹でホウレン草（家系の象徴）

家系ラーメンの代表トッピング。**しゃきしゃき食感を残す**ことが重要。茹ですぎると色も食感も落ちる。

### 材料

| 食材 | 分量 |
|------|------|
| ホウレン草 | 1把（約 200 g） |
| 塩（茹で湯用） | 小さじ1 |

### 工程

1. ホウレン草を流水でよく洗う（根元の砂を念入りに）
2. 鍋に湯を沸かし、塩を加える
3. 根元から先に沸騰湯に入れて **15-20秒**、続けて葉を入れて **さらに10-15秒**（合計 30秒程度）
4. すぐに **氷水に取って色止め**（緑色を保つ）
5. 水気をしっかり絞り、**4-5cm長さに切る**
6. 提供直前まで冷蔵庫で保管

> **当日朝に茹でておけば OK**。1杯あたり 15-20g（約20cm × 4-5cm束 × 2-3枚）。提供時にスープに浸さず**麺の上に乗せる**（しゃきしゃき食感を保つため）。

## 7.5. 裏かっぱ（家系の象徴的副菜・小皿提供）

家系ラーメンの定番裏メニュー。きゅうりベースの清涼感ある副菜で、家系の油脂感に対するキレ役。**ラーメンと並行提供 or ラーメン前の小皿**として。

### 材料（12人前・小皿1人約 30g）

| 食材 | 分量 |
|------|------|
| 青キュウリ | **3-4本**（300-400 g） |
| 家系タレ（既存の豚骨醤油タレを流用） | 大さじ2（30ml） |
| おろしにんにく | 1片分 |
| おろし生姜 | 小さじ1 |
| ごま油 | 大さじ1（15ml） |
| 白ごま | 小さじ1 |
| ちぎり海苔 | 適量（家系らしさ） |
| 鷹の爪輪切り（任意） | 少々 |

### 工程

1. キュウリを **乱切り or 棒切り**（食べやすく）にする
2. 塩 小さじ1/2 をふって 5分置く → 水気を絞る
3. ボウルに キュウリ + 家系タレ + おろしにんにく + おろし生姜 + ごま油 を入れて和える
4. 冷蔵庫で **30分以上馴染ませる**
5. 提供直前に **白ごま + ちぎり海苔** を散らす
6. 小皿に盛って Ramen II と一緒に提供

> **当日朝に仕込んで冷蔵庫で味馴染み**させるとベスト。提供時の鮮度を保つため、海苔は直前に散らす。
>
> **家系における裏かっぱの位置：** 横浜の家系直系店で「裏メニュー」として知られる副菜。豚骨脂と醤油タレの重量感の中でキュウリの清涼感が「もう一口食べたくなる」役割を担う。**コース料理の中ではRamen IIに合わせる小皿**として最適。

## 7.7. 鶏油（プレーン・家系仕様）

家系の伝統的な鶏油。**Ramen I の山椒鶏油精製と同じ工程**だが、**実山椒を投入する前に半量を取り分け**ることでプレーン鶏油も同時に作る。

### 材料

| 食材 | 分量 |
|------|------|
| 比内地鶏の脂（精製済み・山椒投入前の半量） | 約 80 ml（300g精製→160ml の半量） |

### 工程

`recipes/ramen-i-hinai-jidori-chintan.md` の第6章「自家製鶏油（山椒鶏油）」を参照。**精製完了→脂が透明な黄金色になった時点で半量（約80ml）をプレーン鶏油としてRamen II用に取り分け**、残り半量にのみ実山椒8gを投入する。

提供時は **小さじ1（5ml）** をスープ表面に垂らす。家系では鶏油はやや多めが伝統。

> **なぜ山椒を入れないか：** 家系ラーメンの鶏油は素直な鶏の旨みが主役。山椒の存在感は家系の濃厚な豚骨醤油と豚脂感を妨げる可能性がある。Ramen I（清湯）は繊細さに山椒の華やかさを加えるが、Ramen II（家系）は **重厚さで真っ向勝負** の方向性。

7. 焼豚をスライスしてバーナーで炙る

## 9. 仕上げ・盛り付け

### 当日の作業タイムライン

| タイミング | 作業 |
|-----------|------|
| 提供30分前 | 呼び戻しスープを加熱・温度維持 |
| 提供20分前 | 焼豚スライス・バーナーで炙り |
| 提供15分前 | 穂先メンマを温める |
| 提供10分前 | 味玉を半割にカット |
| 提供5分前 | 麺を茹でる |
| 提供直前 | タレ投入 → スープ → 麺 → ホウレン草・トッピング → 鶏油 → 肉醤・かんずり ／ 別小皿で**裏かっぱ** |

### 盛り付け手順（1杯あたり・家系仕様）

1. 温めた丼に**タレ35ml**（家系仕様で増量・元25-30ml）を入れる
2. どろっとした豚骨スープ（**約150ml**）を注いでよく混ぜる
3. 湯切りした**家系中太麺（約60g）を中央に盛る**（茹で時間 1分30秒〜2分）
4. **茹でホウレン草（15-20g）を麺の手前に乗せる**（家系の象徴）
5. スライスした焼豚をバーナーで炙って**2〜3枚**のせる
6. 味玉（半割）・穂先メンマ豚骨版を添える
7. **有明海苔を2-3枚**立てかけるように添える（家系では大判で多め）
8. 白髪ネギを盛る
9. スープ表面に**鶏油（プレーン）を小さじ1**垂らす（家系の伝統・山椒は使わない）
10. 宮崎県産豚の肉醤をスープの表面に**小さじ1程度**乗せる
11. かんずりを**小皿で添える**
12. **別小皿で「裏かっぱ」**（キュウリの家系副菜・30g/人）を Ramen II と一緒に提供

> **かんずりの食べ方：** 添えるだけでなく、スープに溶かして全体に絡める食べ方も伝える。豚骨の脂っぽさを切り、後半の味変として機能する。

### 低加水細麺で失敗を防ぐために

| 対策 | 理由 |
|------|------|
| 加水率40%以上 | 30%台はグルテン形成前に乾燥しボロボロになる |
| 冷水（5℃）使用 | グルテン形成を緩やかにし水分を均一に浸透させる |
| 最初に踏まず冷蔵休み | 少ない水分を粉全体に均一に行き渡らせる |
| 踏み→冷蔵休のサイクル3回 | 無理なくグルテンを形成する |
| ATLAS 150段階的伸ばし | 一気に薄くするとグルテンが切れる。2→3→…→7と段階的に |
