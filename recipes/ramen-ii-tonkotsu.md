## 1. 呼び戻し豚骨スープ

### スープの収支

| 項目 | 量 |
|------|------|
| 既存スープ（旧ダシ・抽出済み） | 2,000 ml |
| 追加ゲンコツ（新規炊き出し） | 4,000 g |
| 炊き出し用水 | 5.0 L |
| 新スープ仕上がり目標 | 約2.5 L |
| 呼び戻し合計 | 約4〜4.5 L |
| 必要量（150ml × 12杯） | 1,800 ml |

> **呼び戻しとは：** 久留米ラーメン発祥の技法。旧スープに新しく炊いたスープを継ぎ足すことで旨みが幾重にも重なる。翌日以降も残ったスープを継ぎ足すことでさらに旨みが深まる。

### 材料

| 食材 | 分量 |
|------|------|
| 豚ゲンコツ（追加・呼び戻し用） | 4,000 g |
| 水（炊き出し用） | 5.0 L |

### 工程

**① 豚ゲンコツの下処理（前日）**

1. ゲンコツを流水で洗い、大きな鍋にたっぷりの冷水を入れ**2時間血抜き**する
2. たっぷりの沸騰湯に投入し**5〜10分茹でてから取り出す**（霜降り処理）
3. 流水でぬめりと血合いをブラシで丁寧に洗い落とす
4. ゲンコツは割って**骨髄が出やすい状態**にしておく

**② 呼び戻しスープの炊き出し（強火・8〜12時間）**

1. 大鍋に下処理したゲンコツと水5.0Lを入れ、最初は**強火で沸騰させる**
2. 沸騰後も**あえて強火を維持**し、白濁した超濃厚スープに仕上げる（久留米系は濁りを恐れない）
3. 途中、蒸発した分だけ湯を足しながら**8〜12時間炊き続ける**
4. 脂とコラーゲンが完全に乳化し、どろっとした超濃厚スープに仕上げる
5. 仕上がり目標：約**2.5L**

**③ 呼び戻しスープの合わせ**

1. 炊き上がった新スープを細目のシノワで濾す
2. 既存の旧スープ（2,000ml）と新スープを鍋に合わせ、弱火でゆっくり混ぜ合わせる
3. 合計約4〜4.5Lを目標とする
4. 使う分だけ都度温め、残りは冷蔵保存（翌日以降もさらに旨みが増す）

## 2. 豚骨醤油タレ

### 材料

| 食材 | 分量 |
|------|------|
| 薄口醤油 | 120 ml |
| 濃口醤油 | 60 ml |
| みりん | 80 ml |
| 日本酒 | 80 ml |
| 焼豚の煮汁（タレ用） | 100 ml |

### 工程

1. みりん・日本酒を小鍋に入れ弱火でアルコールを飛ばす
2. 薄口醤油・濃口醤油を加えて一度温める
3. 焼豚の煮汁を加えてよく混ぜる
4. キャラメリゼした三温糖の香ばしさと豚の旨みがタレに溶け込む
5. 冷ましてから保存容器に移す

> **使用量の目安：** 丼1杯に対して25〜30ml

## 3. 春よ恋 自家製細麺（ATLAS 150仕様）

### 材料

| 食材 | 分量 |
|------|------|
| 春よ恋（強力粉） | 720 g |
| 水（製麺用・冷水5℃前後） | 288 ml |
| かん水 | 7 g |
| 塩（製麺用） | 7 g |
| 乾燥卵白 | 10 g |

> **加水率：40%　/　1杯あたり麺量：約60g**

### なぜ加水率40%か

春よ恋はタンパク質含有量が高く吸水性が強い。32%ではグルテンが形成される前に生地が乾燥してボロボロになる（3cm程度にちぎれる）。40%が春よ恋での最低安全ライン。慣れてきたら38%まで下げて食感の変化を確認するのが良い。

### 工程

**① 加水（分割・3回）**

1. かん水・塩を冷水（5℃前後）に完全に溶かす
2. 春よ恋と乾燥卵白をふるって混ぜておく
3. ボウルに入れ、塩水を**3回に分けて**少しずつ加える
3. そのたびほぐすようにまんべんなく混ぜ、全体に湿気が行き渡ったら次の加水へ
4. 最後は手で押しまとめる程度で止める（練りすぎない）

**② 初回休眠（冷蔵・30分）**

1. 生地をビニール袋に入れ、空気を抜いて密閉する
2. **踏まずそのまま冷蔵庫に30分以上休ませる**
3. 少ない水分を粉全体に均一に浸透させるための重要な工程

**③ 踏み・休ませのサイクル（3回繰り返す）**

1. 冷蔵庫から出して平らな場所で**足で踏む**
2. 生地を広げて一度踏んだら二つ折りにしてまた踏む → 4〜5回繰り返す
3. 生地がまとまってきたら再度ビニール袋に入れ、**冷蔵庫に15分休ませる**
4. このサイクル（踏み→冷蔵休）を**3回**繰り返す

**④ 最終休眠（冷蔵・1時間以上）**

1. 最後の踏み後、ビニール袋に入れたまま**冷蔵庫に1時間以上寝かせる**
2. 生地の跡が出て裂けなくなれば成功

**⑤ ATLAS 150での延び伸ばし**

1. ダイヤル1（最厚）から引き始め、**2→3→4→5→6→7**の順に段階的に伸ばす
2. 各ダイヤルで少なくとも**2回通す**こと（一気に薄くするとグルテンが切れる）
3. ダイヤル6〜7仕上げで**端材を実測して厚さ1.2mmに調整**する
4. 春よ恋は弾力が強く伸ばした直後に若干縮むため、少し薄めに仕上げる意識で伸ばす

**⑥ 1mmカッターでカット・保存**

1. 打ち粉（片栗粉：春よ恋＝1:1）を充分にまぶしてからカッターに通す
2. カット後すぐに麺をほぐしてだんごに丸め、打ち粉をまぶして冷蔵保存
3. 1杯あたり約**60g**

**⑦ 茹で時間**

1. たっぷりの沸騰湯（塩なし）で**45秒〜1分**茹でる
2. 濃厚スープによく絡むよう、**芯が残る程度（やや硬め）**で湯切りする
3. 湯切りはしっかり行い、スープが薄まらないようにする

## 4. 米沢豚バラ 三温糖キャラメリゼ焼豚

### 材料

| 食材 | 分量 |
|------|------|
| 米沢豚バラ肉（ブロック） | 1,500 g |
| 三温糖（キャラメリゼ用） | 60 g |
| 醤油（煮汁用） | 150 ml |
| みりん（煮汁用） | 100 ml |
| 日本酒（煮汁用） | 100 ml |
| 長ネギ（青い部分・煮豚用） | 1本 |
| 生姜（薄切り・煮豚用） | 20 g |

### 工程

**前日仕込み**

1. 豚バラを巻いてタコ糸で縛る
2. フライパンを強火で熱し**三温糖を投入**してキャラメル色になるまで溶かす
3. 溶け始めたらすぐに豚バラの表面全体に絡めながら焼き色をつける（焦がさず均一に）
4. 鍋に移し醤油・みりん・日本酒・長ネギ・生姜と水（ひたひた）を加えて落とし蓋をし、弱火で**90分煮込む**
5. そのまま煮汁ごと一晩冷蔵庫で休ませる

**提供直前**

1. 翌日スライスし、バーナーで表面を焦がす
2. **煮汁は必ず取っておくこと**（タレ・味玉漬けダレに使用）

> **三温糖キャラメリゼのポイント：** フライパンを十分に熱してから三温糖を投入し、溶け始めたらすぐに肉を転がして絡める。焦がさず表面に均一に香ばしさをつけることが重要。煮汁に三温糖の香ばしさが移り、タレと味玉漬けダレに深みが出る。

## 5. 味玉

### 材料

| 食材 | 分量 |
|------|------|
| 卵 | 12個 |
| 焼豚の煮汁（味玉漬けダレ用） | 150 ml |
| 水（漬けダレ希釈用） | 100 ml |

### 工程

1. 卵を沸騰湯に静かに入れ**7分茹でる**
2. 冷水に取って殻をむく
3. 焼豚の煮汁150mlを水100mlで希釈して漬けダレを作る
4. 卵を袋に入れて漬けダレに浸す
5. 冷蔵で**最低12時間以上漬け込む**（24時間漬けると色・味ともにより深くなる）
6. 提供時は半分にカットして断面を見せる

> **焼豚の煮汁を使う理由：** スープ・タレ・焼豚・味玉が同じ煮汁でつながることで、一杯全体に統一感と奥行きが生まれる。

## 6. 穂先メンマの味付け

### 材料

| 食材 | 分量 |
|------|------|
| 穂先メンマ（水煮） | 360 g |
| 醤油（メンマ味付け用） | 30 ml |
| ごま油（メンマ味付け用） | 15 ml |
| 砂糖（メンマ味付け用） | 5 g |

### 工程

1. 穂先メンマの水煮をさっと湯通しして水気を切る
2. 小鍋に醤油・ごま油・砂糖を入れて軽く熱し、穂先メンマを加えて絡める
3. **煮詰めすぎず**、穂先のやわらかい食感を残すことが重要
4. 冷蔵保存し、提供時に温めて使う

> **穂先メンマをそのまま使う理由：** 細切りにすると食感がほぼなくなる。穂先1〜2本をそのまま乗せることでやわらかさがコース仕様の上品さと合い、焼豚との食感の対比も出る。

## 7. 黒マー油

### 材料

| 食材 | 分量 |
|------|------|
| にんにく（黒マー油用） | 60 g |
| ラード（黒マー油用） | 150 ml |

### 工程

1. にんにくを薄くスライスする
2. ラードを小鍋に入れて弱火にかけ、にんにくを投入してじっくり揚げる
3. きつね色を超えて濃い**茶褐色（焦げる一歩手前）**になったら火を止める
4. 粗熱が取れたらにんにくごとミキサーまたはすり鉢で撹拌し、ラードと合わせてペースト状にする
5. 提供時はスープ表面に**小さじ1/2**垂らす

> **濃度調整：** 茶褐色止まりにすることでほろ苦さと香ばしさのバランスが取れる。完全に黒くなるまで焦がすと苦みが強くなりすぎる。ラードを増やすほどマイルドになる。

## 8. トッピングの準備

### 材料

| 食材 | 分量 |
|------|------|
| 有明産一番摘み海苔 | 24枚 |
| 宮崎県産豚の肉醤 | 60 g |
| かんずり六年仕込 | 36 g |
| 長ネギ（白髪ネギ・トッピング用） | 2本 |

### 準備

1. 有明海苔は提供直前まで乾燥した場所で保管（湿気厳禁）
2. 宮崎県産豚の肉醤は小皿に取り分けておく（1杯あたり5g）
3. かんずりは小皿に盛り付ける（1杯あたり3g）
4. 長ネギは細く切り、水にさらして辛みを抜いておく
5. 味玉は半分にカット
6. 穂先メンマを温める
7. 焼豚をスライスしてバーナーで炙る

## 9. 仕上げ・盛り付け

### 当日の作業タイムライン

| タイミング | 作業 |
|-----------|------|
| 提供30分前 | 呼び戻しスープを加熱・温度維持 |
| 提供20分前 | 焼豚スライス・バーナーで炙り |
| 提供15分前 | 穂先メンマを温める |
| 提供10分前 | 味玉を半割にカット |
| 提供5分前 | 麺を茹でる |
| 提供直前 | タレ投入 → スープ → 麺 → トッピング → 黒マー油 → 肉醤・かんずり |

### 盛り付け手順（1杯あたり）

1. 温めた丼に**タレ25〜30ml**を入れる
2. どろっとした豚骨スープ（**約150ml**）を注いでよく混ぜる
3. 湯切りした**細麺（約60g）を中央に盛る**
4. スライスした焼豚をバーナーで炙って**2〜3枚**のせる
5. 味玉（半割）・穂先メンマを添える
6. 有明海苔を**2枚**立てかけるように添える
7. 白髪ネギを盛る
8. スープ表面に**黒マー油を小さじ1/2**垂らす
9. 宮崎県産豚の肉醤をスープの表面に**小さじ1程度**乗せる
10. かんずりを**小皿で添える**

> **かんずりの食べ方：** 添えるだけでなく、スープに溶かして全体に絡める食べ方も伝える。豚骨の脂っぽさを切り、後半の味変として機能する。

### 春よ恋での失敗を防ぐために

| 対策 | 理由 |
|------|------|
| 加水率40%以上 | 32%はグルテン形成前に乾燥しボロボロになる |
| 冷水（5℃）使用 | グルテン形成を緩やかにし水分を均一に浸透させる |
| 最初に踏まず冷蔵休み | 少ない水分を粉全体に均一に行き渡らせる |
| 踏み→冷蔵休のサイクル3回 | 無理なくグルテンを形成する |
| ATLAS 150段階的伸ばし | 一気に薄くするとグルテンが切れる。2→3→…→7と段階的に |
