# Unit: Noodle Craft — 製麺ノウハウ（横断）

## Intent
Ramen I（清湯・平打ち 3.5mm）と Ramen II（家系・中太 1mm × 厚み 2mm）の両 Unit が参照する製麺の共通ノウハウ。粉選定指針・加水率・伸ばし方・カット幅などを集約。

## Success Criteria
- 両 ramen Unit の麺仕様を支える前提知識が一箇所に整理されている
- 試作記録（各 Unit 配下の bolt）と紐づき、改訂時の根拠が辿れる
