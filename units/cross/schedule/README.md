## 失敗時のリカバリープラン

| 問題                       | 対策                                                     |
| -------------------------- | -------------------------------------------------------- |
| 麺が足りない               | 予備の乾麺を買っておく（¥200〜300）                      |
| 麺がちぎれた               | 短い麺でも盛り付けでカバー。「手打ちの証です」           |
| スープが足りない           | 1杯のスープ量を減らす（清湯95ml→80ml / 家系150ml→120ml） |
| スープが濁った（清湯）     | 「白湯風にアレンジしました」と言い切る                   |
| 焦がした                   | 焦げた部分を除去して使える分だけ使う                     |
| 味が薄い                   | タレを追加投入で調整                                     |
| 味が濃い                   | スープで薄める                                           |
| パイが崩れた               | 崩れた部分を下にして盛り付け。マデイラソースで隠す       |
| 時間が押している           | グラニテを省略してRamen II に直行                        |
| **マデイラソース割れた**   | 弱火で冷たいマデイラ追加→木べらで再乳化                  |
| **コンフィチュールが固い** | 弱火で温め直し or レモン果汁少量追加                     |
| **メンマ味薄い**           | 温め時に醤油1-2滴追加（清湯版は薄口、豚骨版は再仕込）    |
| 製麺2次熟成が不足          | 麺の腰が弱いので**茹で時間を10秒短く**                   |
