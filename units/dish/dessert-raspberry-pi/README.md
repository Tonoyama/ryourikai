# Unit: Dessert — Raspberry Pi スナップドラゴン添え

## Intent
コースを締めるデザート。ラズベリーパッセコンフィチュール・バニラとトンカ豆のアイス・マデイラレデュイールを組み合わせ、スナップドラゴンを添えて視覚と香りの記憶を残す。

## Success Criteria
- コンフィチュールの酸味と砂糖のバランス（砂糖 50%）
- アイスのトンカ豆香りが奥行きを作る
- マデイラレデュイールがバニラ・オレンジ皮・シナモンで複層的に決まる

## Components
- `recipe.md` — メインのラズベリーパイ組立
- `madeira-reduction.md` — マデイラレデュイール（無塩バター仕上げ）
- `vanilla-tonka-ice-cream.md` — バニラ＆トンカ豆アイス（600g・クネル提供）

## Dependencies
- `units/cross/procurement` — ラズベリー・バニラペースト・トンカ豆・マデイラ酒
- `units/cross/schedule` — D-1 コンフィチュール仕込み・D-Day アイス成形
