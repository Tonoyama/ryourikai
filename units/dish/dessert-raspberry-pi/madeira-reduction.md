# ソース・マデイラ・レデュイール・モンテ・ド・ブール（Sauce Madère Réduit Monté au Beurre／12人前）

スイートマデイラを 1/3 量まで煮詰め、火を止めてからバニラペースト・無塩バターを加えて乳化させた、コクと艶を両立したデザートソース。**バニラアイスとの香りの同調、パイ（紅ほっぺ + ラズベリー + マデイラ漬けいちご）の甘酸との対比**を狙う。元レシピのソースガストリック（カラメル + バルサミコ）を置き換える。

## 手順

### 1. アロマを抽出しながら煮詰める

1. 小鍋に **マデイラ 250ml**、**オレンジ皮 1/2個分**（白いワタを除く外皮のみ）、**シナモンスティック 1/2本** を入れる
2. **弱中火** で **1/3量（約80ml）** まで煮詰める（約20分）
3. 沸騰させすぎず、表面が静かに泡立つ程度の火加減を維持する

> **目安：** スプーンを通した時に薄い膜が引く程度。冷えるとさらにとろみが増すので、**やや緩めで止める**。

### 2. アロマを取り除く

1. 火を止める前にシナモンスティックとオレンジ皮を取り出す
2. **火を止めて鍋を火から外す**

### 3. バニラペーストを溶かす

1. **火を止めた状態で** バニラペースト小さじ1/2 を加える
2. 木べら or スプーンで完全に溶かす
3. 種の粒子が均一に散ったらOK

> **加熱しない理由：** バニリン等の香り成分は 80℃以上の長時間加熱で揮発する。鞘ごと煮出す方式と違って、ペーストは香りが既に解放されているので追加熱不要。

### 4. バターでモンテ（乳化）

1. **冷たい無塩バター 10g** を投入
2. 鍋を **ゆっくり傾けながら回す**（鍋肌の余熱でバターが少しずつ溶ける）
3. 全体が乳化してとろみと艶が出るまで継続
4. 沸騰させない（**60℃以下で止める**）。沸騰すると油脂が分離して「割れる」

> **モンテ・ド・ブールとは：** フランス料理の艶出し技法。火を止めた液体に冷たいバターを少しずつ加えて乳化させる。沸騰NG。

### 5. 仕上げ

1. **海塩ひとつまみ** で甘みの輪郭を引き締める
2. 味見：甘×コク×香り×塩のバランスを確認
3. 完全に冷ましてから密閉容器で **冷蔵保存**

---

## 提供時の温め直し

1. 容器ごと湯煎にかける（鍋に湯を張ってボウルを浮かべる）
2. **弱火**で攪拌しながら 50〜55℃ まで温める
3. **絶対に沸騰させない**（バター分離）
4. パイの上または横に敷くようにかける

## 味の設計意図

| 要素 | コントリビューション |
|------|------|
| マデイラ（甘・コク） | 主柱：3年〜熟成スイートマデイラの干しブドウ感とコク |
| バニラペースト | バニラアイスと**香りの同調**でブリッジ |
| オレンジ皮 | ヘスペリジン由来の爽快感、重さを軽減 |
| シナモン | パイの暖かさと呼応、ラズベリーとも好相性 |
| バター | 艶・口溶け・コク、見た目の格をガストリック以上に |
| 海塩 | 甘みの輪郭を立てる（ソルティーキャラメル原理） |

## ガストリックから置き換えた理由

| 観点 | ガストリック（旧） | マデイラレデュイール（新） |
|------|------------------|--------------------------|
| 甘 | カラメル化糖 | スイートマデイラ＋熟成糖 |
| 酸 | バルサミコ酢 | **パイ側に任せる**（紅ほっぺ・ラズベリー・マデイラ漬けいちご） |
| 苦 | 濃い琥珀カラメル | わずか（マデイラの渋み） |
| 香り | 単層（カラメル＋酢） | **多層**（マデイラ＋バニラ＋オレンジ＋シナモン） |
| 艶 | 油脂なし（光沢弱） | **バターでの乳化艶** |
| 危険性 | 沸騰バルサミコの跳ね | バターモンテの分離注意のみ |

→ パイ側で **既に酸味が担保されている**ため、ソース側は「深いコク × 多層香り × 艶」に振った方が全体バランスが整う。

---

## 注意点・トラブルシューティング

| トラブル | 原因 | 対処 |
|---------|------|------|
| バターが分離した | 沸騰させた | 弱火で少量の冷たいマデイラ追加→再乳化 |
| 苦すぎる | 煮詰めすぎ | 少量のマデイラを加えて薄める |
| 甘すぎる | 煮詰め不足 | 弱火でさらに5分煮詰める |
| とろみが弱い | 煮詰め不足 / バター少なめ | 弱火で煮詰めるか、冷蔵すると自然に締まる |
| シナモン香り強すぎ | 入れすぎ・煮込みすぎ | 次回は 1/4本に減らす |
