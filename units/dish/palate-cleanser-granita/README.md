# Unit: お口直し — 静岡 手摘み新生茶葉のグラニテ

## Intent
Ramen I から Ramen II への味覚切り替え。静岡手摘み新生茶葉のグラニテに広島レモンの香りを添えて口腔をリセットする。

## Success Criteria
- グラニテの粒度がさくっと崩れる
- レモン香が新茶を覆い隠さない
- 提供時に冷えている

## Components
- `recipe.md` — グラニテ仕込み・盛り付け

## Dependencies
- `units/cross/procurement` — 新生茶葉・レモン
- `units/cross/schedule` — 冷凍庫スペース確保・提供タイミング
