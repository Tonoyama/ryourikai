# Unit: Ramen I — 比内地鶏とアサリの清湯ラーメン

## Intent
コース仕様の清湯ラーメン。比内地鶏 7：アサリ 3 のスープで奥行きを出し、自家製平打ち麺・比内地鶏ツミレ（実山椒風味）・雲呑・焼き夏長ネギ・穂先メンマで構成する。一杯95gの少量・高密度設計。

## Success Criteria
- スープ 95g/杯（比内地鶏 66.5g + アサリ 28.5g）
- タレ 22ml/杯、塩分濃度 1.5%
- 麺は平打ち 3.5mm（特ナンバーワン 70% + 飛行船 30%、加水率 43%）
- 比内地鶏ツミレに実山椒の香り
