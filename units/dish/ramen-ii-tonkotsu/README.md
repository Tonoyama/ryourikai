# Unit: Ramen II — 俺たちの濃厚豚骨ラーメン（家系派生）

## Intent

コースのメインクライマックス。豚骨ベースに家系の伝統に則ったトッピング（豚焼豚・味玉・茹でホウレン草・大判海苔）と裏かっぱ（青キュウリ家系副菜）を添え、エンジニア仲間が「これだ」と言える一杯を目指す。

## Success Criteria

- スープ 150ml/杯、塩分濃度 1.8〜2.0%
- 家系中太麺（1mm × 厚み 2mm、加水率 33%、特飛龍 60% + 勇 40%）
- 豚骨 2L 以上の歩留まり（ゲンコツ 4kg + 背がら）
- 豚焼豚の食感（圧力鍋仕様）

## Components

- `recipe.md` — 全工程レシピ

## Dependencies

- `units/cross/noodle-craft` — 製麺基礎ノウハウ
- `units/cross/procurement` — ゲンコツ・背がら・豚・調味料
- `units/cross/schedule` — D-1 豚骨炊き・D-Day 仕上げ
- `units/cross/hospitality` — 配膳・かんずり/肉醤の案内

## Volume (12人前)

- 麺粉: 特飛龍 720g + 勇 480g（20人前仕様）
- スープ: 1,800ml（仕込み余裕込み 2.7〜2.8L）
- ゲンコツ 4kg + 背がら 4kg → 約 4L
