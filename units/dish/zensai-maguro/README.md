# Unit: 前菜 — 長崎 生本鮪中落ち

## Intent
コース1番目。長崎産生本鮪中落ちを青種・赤種わさび 2種・愛知 三年木桶熟成たまりと合わせ、後続のラーメン体験へ向けた味覚の導入を担う。

## Success Criteria
- 鮪中落ちのとろみとフレッシュさが活きている
- 青種・赤種わさびを摺り比べ、両者の香り・辛味の違いをゲスト自身が体験できる
- 三年木桶熟成たまりの濃厚さで一口目の輪郭が決まる

## Components
- `recipe.md` — 切り出し・盛り付け・提供フロー

## Dependencies
- `units/cross/procurement` — 鮪中落ち・青種わさび・赤種わさび・三年木桶熟成たまりの調達
- `units/cross/schedule` — 当日提供タイミング（コース冒頭）
- `units/cross/hospitality` — 一皿目の説明・体験設計

## Bolts
